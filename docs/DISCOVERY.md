# 番剧查找改进

参考检查：2026-09-23，实际浏览 [girigiri 首页](https://ani.yeuxark.com/)、[分类页](https://ani.yeuxark.com/show/2-----------/) 和番剧详情。

参考站的长处是多条找番路径相互连通：周期表、分类与年份等组合筛选、排序分页、搜索记录、详情标签。映序原先只有来源推荐和关键词搜索，适合已知片名，缺少逛片库的入口。

v0.7.0 当前能力：

| 需求             | Sardina anime 处理                                                                                                                                                                |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 不知道片名时找番 | 独立番剧索引，接入来源真实目录接口                                                                                                                                                |
| 组合筛选         | AniCh：类型、语言、年份；Aki：题材、年份、排序；girigiri：分类、题材、季度、年份、语言、形式、改编与排序；咕咕：番剧/剧场版、题材、排序；乐豆：地区、年份、排序；稀饭：年份、类型 |
| 大片库导航       | AniCh 按续页标记逐页浏览；其他来源按真实页码或完整目录浏览。只有上游提供可靠总数时才展示总条数和页数                                                                              |
| 每天看什么       | Aki 和 girigiri 公开周期表，按星期读取，点入现有详情和播放链路                                                                                                                    |
| 重复查找         | 最近搜索存入共享 SQLite，可删除；备份兼容旧格式                                                                                                                                   |
| 搜索结果太杂     | 先由用户选择单一来源，只请求该源；再按已返回结果的年份、类型筛选和排序；海报/列表视图                                                                                             |
| 点进详情后迷路   | 带回来源页、筛选和页码；详情年份链接到同源索引                                                                                                                                    |
| 热门与评分参考   | 发现页 girigiri「最近大家在看」；「热门与高分」按来源热度/评分排序；详情展示站点评分与 Bangumi 评分、人数、排名，支持确认条目关联                                                 |

界面使用灰纸浅色与星空黑深色，小型 Sardina anime 鱼标；发现页直接呈现内容，不设大型字标或背景封面墙。紧凑筛选区左对齐，海报为主体。当前配色与交互见 [界面设计](design.md)。

评分出处、谨慎匹配与热门数据的口径见 [评分与热门说明](RATINGS.md)。

番剧索引                         刷新

年份       全部 / 2026 / 2025 ...

复核：筛选直接请求来源目录，而非只在首页十几张海报中筛选。不同来源能力明确呈现，切源清除不支持的条件。季度只在 girigiri 等已实现来源出现，地区只在实际支持的来源出现。周期表是来源提供的放送安排，不能推断为已经更新或确认可播放。评分排序由来源提供，不合并成应用评分。

girigiri 关键词搜索要求验证码时，搜索页显示本站原图，等待用户输入；当前源尚未返回的搜索不会混入其他来源结果。切换来源释放原验证会话；索引和日历仍可独立使用。咕咕、乐豆列表不返回可靠总数，实际检查下一页 ID 后决定是否继续，不伪造“共多少部”。稀饭读取公开 RPC 的 `total_count`，2024 年 TV 分类验证返回总数 191、第一页 24 条；其搜索可能匹配简介等资料，不擅自缩成标题完全匹配。

实站检查纠正了原脚本中的分页假设：AniCh 的 `skip` 是上一次响应根消息字段 3 返回的续页标记，而非 30 条一页的偏移量。目录与关键词搜索都改为传递此标记；固定样本覆盖不足 50 条仍有下一页、末页、返回和重新加载。Aki 的周期表返回 `/bgmplay/ID-线路-集.html`，需要提取番剧 ID 再进入本地详情页，不能用目录 JSON 中的数字 `vod_id`。

v0.2.0 阶段的独立检查中，Aki 年份 2024 + 恋爱 + 评分排序曾返回 43 条中的前 40 条，周期表原始响应曾返回周三 6 条；后续完整复查遇到 Aki 504、AniCh 502，浏览器同样可复现 Aki 504。AniCh 恢复后，目录连续两页各 50 条、无重复；搜索“异世界”两页分别 50、46 条并正确结束。失败与恢复记录均保留在 `validation/discovery-live.json`。Aki 周期表解析修正后的真实成功复查仍待来源恢复，固定样本通过不代表来源当前在线。

AniCh 的年份分类偶尔与详情不一致，条目 `34577` 在 2024 分类出现，但详情年份为 2025。因此不将选中的年份或类型复制成番剧的确认资料，缺失元数据保留未知。页面展示具体错误、刷新和切源入口。

接口与边界：`/api/v1/catalog`、`/api/v1/schedule`、`/api/v1/search-history` 沿用本地鉴权、来源启停、网络校验与取消机制；目录与日历短期缓存。新增来源共用现有详情、选集、播放器、追番和进度保存；具体线路范围见 [来源清单](SOURCES.md)。
