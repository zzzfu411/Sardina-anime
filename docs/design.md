# Sardina anime 界面设计

## 索引字号（2026-09-25）

按用户反馈提高索引阅读尺寸：筛选、排序、页码与操作按钮为 16px，番剧标题为 18px，来源与辅助说明为 14px，列表简介为 15px。海报与列表视图共用该字号层次，筛选按钮增加留白；规则限定在索引及共用该页面的热门浏览。手机不缩回小字号，筛选按钮至少 44px 高。

类型检查及构建通过。在 1440 / 768 / 390 / 320px 下检查海报和列表共八组布局，字体均达到指定尺寸且无横向溢出。深浅色截图在 `output/playwright/catalog-type-{light,dark}-2026-09-25.png`。

## 封面圆角与悬停反馈（2026-09-25）

依据用户提供的 girigiri 截图，常规封面改为 12px 圆角，小尺寸封面使用 6–8px。鼠标悬停或键盘聚焦时，图片在裁切框内放大到 1.045 倍，叠加 18% 暗色遮罩，保留播放图标；使用 260ms 缓动，封面框、标题和网格位置保持不变。首页、索引、搜索及资料库共用效果，详情静态封面只调整圆角。沿用灰纸浅色与星空黑配色。

触屏不依赖悬停；减少动态效果时关闭缩放及过渡，仍保留暗色与焦点提示。构建通过，真实来源页面验证了两套主题、键盘聚焦、减少动态效果和 390px 窄屏，常规海报悬停前后尺寸一致。截图在 `output/playwright/cover-hover-{light,dark}-2026-09-25.png`。本次只更新共享样式与网页版构建，未重打包安装包。

2026-09-24，按用户最终修订保留原来的 Sardina 手写字体，只重绘 anime 小字。鱼标恢复 0.6.0 的原图，并仅做水平镜像，保留原姿态与笔画；没有继续使用新画的鱼或粗衬线字标。

UI/UX Pro Max 的文字间距与图标语义建议用于紧凑布局和完整无障碍名称；本轮不引入新的图标库或改变页面配色。原图、翻转资源与小字生成提示词见 [品牌说明](BRANDING.md)。

## 0.6.0：简洁发现页与单来源搜索

2026-09-24，按用户修订：发现页移除集中搜索、大字标及装饰封面墙，保留全局工具栏、小型侧栏品牌、内容推荐、继续观看与放送入口。浅色灰纸、深色星空黑沿用 0.5.0 的色彩和排版层次。

品牌改为 **Sardina anime**，使用 handdraw #097 的沙丁鱼与动画播放画面，呼应 Sardina manga 的侧身阅读小鱼。透明原图、网页缩略图、macOS ICNS 和中英提示词见 [品牌说明](BRANDING.md)。画风编号图与漫画版 Logo 均作为内置图像工具的参考输入；没有给首页增加大型插画。

搜索以来源为选择入口。顶部紧凑选择框允许先选来源再输入；搜索页列出可搜索的已启用来源按钮，每次只发起一个来源的 SSE 请求。切换来源立即重建搜索状态、取消旧请求并释放验证会话，旧结果不会暂留在新来源下。待验证、失败及无结果都属于当前来源；未选来源不显示结果数量或错误。验证码通过后继续原页，分页维持当前来源会话。

来源选择通过按钮的 `aria-pressed`、清楚的状态文字与键盘焦点表达，窄屏自动换行；API 同时校验来源及分页参数，避免界面仅隐藏其他源结果。类型、年份与排序只筛选当前源已返回条目，切源清空不通用的筛选。保留不同源内 ID 的同名条目。

采用本机 frontend-design、macos-design、UI UX Pro Max 与 handdraw-style-prompter。UI UX Pro Max 的通用设计查询不匹配本次修订，未采用；进一步查询 Filter Feedback 后只采用来源按钮换行和清楚反馈，保持现有字体及配色。浏览器结果与安装包验证见 [验收记录](VALIDATION.md)。以下章节为历史记录，首页和搜索行为以本节为准。

## 0.4.1 设计方案

用完整竖版动漫封面作为主视觉，搭配明朝体标题和无衬线操作文字。主推荐旁是同来源的三部选片，以尺寸和疏密区分主次。推荐文案直接来自来源，不编造评分、排名或编辑评价。首页继续只请求选中的来源。

- 配色：纸白 `#f7f5f0`、书页白 `#fffefa`、墨色 `#292b29`、灰墨 `#676a63`、朱红 `#b6382c`、细线 `#d9d7cf`。朱红只用于选中标记、焦点、进度和少量字色；主观看按钮用墨色。
- 字体：本机 Songti SC / Hiragino Mincho ProN 为封面与页面标题；苹方和系统字体为控件、正文。标题 28–38px，正文 14px，说明 12px。无字体网络请求。
- 层次：封面保留比例并使用纸边与轻阴影；页面主体无大块底色，章节用间距和细线组织；按钮圆角小于海报，不把每个区域都变成卡片。
- 浅色成为默认。深色保留相同排版，采用温和墨色与浅朱红，播放器继续使用深色操作区。

## 设计判断

UI UX Pro Max 首次查询返回音乐产品方案，不匹配本应用；缩小到 `video streaming OTT` 后匹配视频流媒体。采用海报优先和安静的背景层级，将其红黑配色调整为石墨灰与低饱和樱花色，以适应中文动画海报。浅色外观单独设计，不反转深色值。

Mac skill 的营销式引导、假窗口按钮和通用拖放不适用于所有页面：浏览器保留真实浏览器操作，Electron 使用已有原生窗口按钮；备份恢复支持文件拖放并保留按钮入口和原有恢复确认。无需引导弹窗即可观看。

## 交互约定

- 深色默认，可切换浅色或跟随系统；偏好保存于现有本地设置并随备份导出。
- `⌘K` / `Ctrl+K` 聚焦搜索，`⌘,` / `Ctrl+,` 打开设置。保留浏览器查找等系统快捷键。
- 播放时单按 `←` / `→` 后退 / 前进 5 秒；右箭头在松键时确认轻按，按住 350 ms 则临时使用 2 倍速，不额外跳转进度。松键、失焦、页面隐藏、暂停、媒体重置或切集后恢复原倍速；临时倍速不写入设置。按用户要求不增加倍速浮层或额外提示，输入框和其他交互控件保留各自的键盘操作。
- 更多导航使用原生 dialog，支持 Escape、焦点约束与关闭后返回触发控件。
- 手机索引默认收起长筛选列表，保留来源与已选条件；展开后所有筛选仍可使用。窄屏设置页的来源说明与操作按钮分行，避免文字被压缩。
- 选中、焦点、错误同时用形态或文字表达；遵循 reduced-motion 和安全区。
- 来源推荐仍按需加载，保留 girigiri 优先及既有缓存优化；不增加自动轮播、背景视频、字体网络请求或动画库。
