# girigiri 弹幕与观看人数

工作区 v0.7.2，检查日期 2026-09-26。仅接入 girigiri 当前播放线路；不发送弹幕，也不读取其他来源的弹幕。

## 使用

通过 `Start Web.command` 打开新构建的网页版，在 girigiri 播放页面下方点击「弹幕」开启。默认关闭；开关、透明度、字号写入本机资料库并进入备份。弹幕未能读取时可单独重试，视频继续播放；已读取内容在刷新失败时保留。外部或站内其中一支失败会明确提示降级；无内容会显示「本集暂时没有弹幕」。

人数显示为「girigiri · 本线路 N 人在看（进入时）」，提示中包含采样时间。它表示进入本集、本线路时来源返回的人数；不同媒体地址/线路的统计可能不同，不能解释为整部作品或本站用户的实时总人数。有效 0 与获取失败分别显示；不会用 0 填补错误。

## 公开协议依据

从 [公开播放页](https://ani.yeuxark.com/playGV27030-1-1/) 的播放器配置追踪到 girigiri 的 [播放器脚本](https://giri.moemoekyu.com/addons/aplyer/atom.obfuscated.js)、[APlayer](https://giri.moemoekyu.com/addons/aplyer/js/atom/APlayer.min.js) 和 [XML worker](https://giri.moemoekyu.com/addons/aplyer/js/danmuWoker.js)。仅静态阅读协议，自行实现界面，不在产品中执行或嵌入第三方播放器脚本。

固定 API 为 `https://m3u8.girigirilove.com/api.php/Scrolling/`，以下均使用 POST JSON：

| 路径 | 请求 | 响应语义 |
| --- | --- | --- |
| `getScrolling` | 已解析的 `play_url` | `info[]` 中的站内弹幕 |
| `getVodOutScrolling` | 同上 | `info` 为外部 XML 地址或空值 |
| `playOnline` | 同上，加 `do: open/close` | 登记/离开并返回 `info.count` |

站内弹幕以 `scroll_json.time`（秒）、`content`、`style.color` 为准，mode 1/2/3 对应滚动/顶部/底部。XML 的 `p` 按时间、模式、字号、颜色等字段解析，1/2/3 为普通滚动，4 为底部，5 为顶部；其余特效模式跳过。外部 XML 仅开放已验证的 `akua.girigirilove.com` HTTPS `.xml` 地址，保留现有 DNS/IP、重定向与端口限制。

目前读取到的原站播放器在进入和 `pagehide` 时调用人数接口，没有持续读取人数的流程。真实配对探针进入返回 8、离开返回 7，因此重复 `open` 会改变统计；本实现不把它当作只读查询。该数字仅是探测时的结果，不是当前人数。

## 播放与资源边界

- 弹幕是纯文本 Canvas 叠层，依据 `video.currentTime` 排布，支持暂停、拖动、倍速、尺寸变化与容器全屏；不拦截原生播放控件。
- 分离滚动和固定轨道，滚动速度一致以免追尾。桌面最多同时 24 条、窄屏最多 12 条；显示文本截断至 80 字符/85% 画宽，保留底部至少 64 px 或 28% 画高给字幕和控件。系统减少动态效果时以固定文字显示。
- 读取最多每支 8 MiB，去重排序后最多输出 20,000 条并报告实际总量/截断；单条数据最多保留 300 字符，时间、模式、颜色经过规范化。弹幕独立缓存，不污染播放源健康状态。
- 暂停、缓冲、隐藏、卸载会停止不必要的绘制；切集清理监听器、计时器、Canvas 与前端数据。视频刷新后重新读取弹幕，但人数沿用同一播放会话的首次登记地址。
- 人数按会话去重，本地心跳不重新登记上游。正常离开、过期、淘汰或引擎关闭配对一次离开；关闭先于登记响应也能配对。会话持有永久关闭标记，避免有界 tombstone 被淘汰后旧请求再次登记。
- 网络中断或引擎被强制杀死时不能保证来源收到离开；上游也没有幂等登记 ID，因此不自动重试可能已经执行过的登记/离开。这里展示来源统计，不承诺人数绝对精确。

## 验证与限制

正式适配器联网读取返回 **3,263** 条有效弹幕（滚动 2,836、顶部 389、底部 38），约 3.5 秒，无截断或降级。浏览器功能验证使用原创 MP4/HLS 与独立内存资料，覆盖实际 Canvas 绘制、暂停静止、拖动、全屏、设置保存、320 像素布局、空态、故障恢复、切集、人数失败/有效 0、减少动态效果及倍速。

具体测试数量见 [验收记录](VALIDATION.md) 和 [机器记录](validation/danmaku-2026-09-26.json)。原始来源响应仅保存在忽略的 `.cache/` 内，公开记录不含签名媒体地址、Cookie 或用户资料。

画中画及部分浏览器的原生视频全屏不包含网页叠层；要同时显示弹幕，请使用应用的全屏按钮。未重跑 Safari、真实来源整集、新 macOS 安装包或强制断电恢复；已有 v0.7.0 安装包没有此次新增功能。
