## 一致性边界

- 收藏状态、剧集完成、观看位置和更新提醒分别表示不同事实，不再用进入播放页代替确认更新。
- 新增 HistoryVersion.profile 是资料库内部身份，不进入便携备份。随机本机端口被另一资料库复用时，旧待写记录不能写入新资料库。旧的无身份 API 请求保留兼容。
- 手动完成固定使用界面读取的版本，不在等待期间自动换用恢复后的版本；最终界面更新只来自保存队列的受保护确认。
- 暂停且未变化的样本不重新生成时间戳；重试沿用同一条样本，避免旧窗口抢回“最近观看”。
- 设置在本机资料库中保留独立 generation，恢复时与数据事务一起更新；旧来源偏好和普通设置请求被拒绝，前端不将旧意图重放到新资料。该身份不进入便携备份。
- 恢复保留设置 revision 递增、提前校验和事务，取消旧更新检查。升级仍保留迁移前备份；v1 JSON 备份新增字段可选。
- 所有已确认进度保存至 SQLite。尚未确认的浏览器待写记录只在原浏览器、原本机地址下自动恢复；清除浏览器数据、换浏览器或重启引擎分配新端口不承诺自动迁移。界面提示应在当前页重试成功后退出。

本轮固定来源和原创短 MP4/HLS 验证不能证明真实来源持续在线、全片库可播或物理休眠恢复；未重跑 Safari、真实来源整集或重新打包安装。构建仍有播放器 HLS chunk 大于 500 kB 的提示，该模块按需加载；没有为压低警告而改动解码路径。
