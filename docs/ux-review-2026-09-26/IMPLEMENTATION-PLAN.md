## 工程约束

- 基于当前工作区增量修改。初始源码及测试快照保存在 `.cache/ux-fixes-baseline-2026-09-26`，不覆盖已有改动。

- 数据修改采用事务；删除与恢复设版本边界，迟到请求不得恢复已删除资料。新增可选字段兼容已有数据库与 v1 备份，并测试升级与回退场景。

- 优先复用现有 React Query、SQLite 和测试设施；不为这些修复引入新的运行依赖。
- 所有测试在内存或独立临时数据库进行。日常使用的数据库、运行中的应用和安装包不作为测试目标。
- 单项完成需要根因、实现、回归证据三者对应；最终再做整体验收。不能用测试通过宣称不存在任何未来缺陷。
