## 稀饭与花子资料

- 稀饭：已接入新版网站的公开 Supabase 目录 RPC 与 `issue-web-playback`，不沿用 Android 的签发流程。仅开放实际完成起播、拖动和续播的 `xfxf1`（来源 ID 4）。联通 CDN 的 `https://bjdownload.pan.wo.cn:30443` 作为这一适配器的精确端口例外，仍检查公开 IP 和每次重定向；没有放宽其他来源的端口。
- 2026-09-25 稀饭配置更新：旧 `api.xifandm.net` 返回 `Unregistered API key`；官网已换用 `api.xifanacg.com` 和新的公开 publishable key。适配器 1.0.1 已同步，推荐、搜索、索引、公开详情及一条 MP4 Range 请求复查通过；未将这次接口复查计作整集播放验收。见 [401 根因与复查记录](validation/xifan-api-2026-09-25.json)。
- 花子：当前域名及两个备用域名的健康接口探测均未成功。安装包还记录了带签名/加密的配置与多个后端，它们不是同一个已经验证的源。AGE 公共首页可读，但只做到入口检查，未列为已接入。
- 漫画四项 `kumanxing/xfy/yulu/zmh`、两个弹幕项及豆瓣资料索引不属于视频播放源，按当前产品范围保留研究资料。

## v0.7.2 girigiri 弹幕与人数（2026-09-26）

girigiri 适配器 1.2.0 新增 `danmaku` / `audience` 能力。正式 HttpClient 实测读到 3,263 条有效弹幕，包含站内与外部 XML；人数接口通过一次配对登记/离开验证。来源目前的播放器只在进出时返回人数，应用标记为本集、本线路的「进入时」快照。发送弹幕与其他来源弹幕尚未接入。公共协议依据、域名白名单和限制见 [说明](DANMAKU.md)，结果见 [验收记录](validation/danmaku-2026-09-26.json)。

## v0.7.0 评分与热门补充（2026-09-24）

girigiri 站内投票与「番」展示分已分别接入；首页「最近大家在看」读取原区域。girigiri、AkiAnime、乐豆的热度排序本轮实测可读，均未公开可核验的统计周期，因此不称为周榜。Bangumi 使用独立公共元数据接口提供评分、人数、排名，详见 [评分说明](RATINGS.md) 和 [实测记录](validation/ratings-live.json)。稀饭 `bangumi_score` / `bangumi_rating_total` 已解析为来源快照，但本轮公开接口返回 401，不能据旧样本声称当前可用。
